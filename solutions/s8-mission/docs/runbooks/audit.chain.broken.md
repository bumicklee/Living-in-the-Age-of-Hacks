# audit.chain.broken

- 심각도: P1 · 담당: 보안 당번(가짜: security@daon.example) · 기준 시간: 확인 15분 · 첫 조치 1시간
- 뜻: 감사 로그 파일의 줄이 지워졌거나 바뀌었다(앞 줄 해시 불일치), 또는 끝 줄이 지워졌다(머리 해시 불일치). 감사받는 사람이 흔적을 지웠을 수 있다(8-6).

## 1. 먼저 볼 질의

```
make audit-verify                       # 끊긴 위치(seq)
{stream="audit"} | json | seq >= <끊긴 seq - 3>     # Loki에 남은 사본(앱이 지울 수 없는 곳)
```
- 지워진 줄의 action·actor·count를 Loki 사본에서 읽는다. 그 시간에 앱 컨테이너에 들어간 사람(작업 기록)을 본다.

## 2. 첫 조치

- 감사 로그 파일과 볼륨을 그대로 보존(복사본 만들기, 덮어쓰지 않기). 앱 컨테이너 접근 권한을 가진 계정을 확인하고 잠근다.
- 되돌리기: 파일을 고치지 않는다. 증거로 남기고, 새 줄은 이어서 쌓인다.

# 최초 코드 점검 · 가게 예제 앱(spring-shop · express-shop)

v0.1 · 15-4 견본 · 작성 다온마켓 강의(견본)

- 점검 대상: `packages/examples/spring-shop`·`packages/examples/express-shop`(부품을 붙이기 전, `make goto L=15-4`의 시작 지점)
- 범위: 로그인 `POST /api/login`, 주문 `GET /api/orders/{id}`, 관리자 회원 상세 `GET /api/admin/members/{id}`
- 방법: ① 정적(검색 규칙: 오류 응답 설정 `include-stacktrace`·`err.stack`, 로그인 처리기의 실패 횟수 확인, 관리자 조회의 감사 기록) ② 의존성(가게 앱은 Spring Boot·express 하나씩, OSV·npm audit은 15-3 방법 그대로) ③ 시크릿(gitleaks + 6-2 규칙, 찾은 것 없음) ④ 실행(127.0.0.1의 예제 앱, 읽기 요청과 틀린 비밀번호 로그인 6번만)
- 하지 않은 것: 상태를 바꾸는 요청(가게 앱은 쓰기 기능이 없다), 공격 페이로드, 운영 환경 요청
- 근거 폴더: `make kit-contract APPS=spring-shop,express-shop`의 출력(시작 지점 레드 3 × 2)
- 출처 분류: [프레임워크 기본값] · [우리 설정] · [우리 코드] · [외부 부품]
- 심각도: 다온마켓 정의를 그대로 쓴다(치명 · 높음 · 중간 · 낮음)

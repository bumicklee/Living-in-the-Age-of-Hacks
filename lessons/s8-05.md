# 8-5 로그 속 토큰·전화번호 가리기
⏱ 약 9분 · 고칠 파일 자바 2개·설정 2개 + 새 파일 3개 · 아키텍처 A5 그대로 · 방어 스위치 `log-mask`

로그인 한 번에 평문 비밀번호와 발급 토큰이 요청 기록(`WebLogAspect`)에 남습니다(F35). 8-4 덕분에 같은 값이 Loki에도 들어갑니다. 로그가 개인정보·비밀의 사본이 된 것입니다.

## 따라 하기
1. **레드인 것부터 봅니다.**
   ```bash
   make goto L=8-5
   make replay T=21        # 가짜 회원 로그인·주문·관리자 조회 뒤 「비밀번호 값 N줄 · JWT 모양 N줄 · 휴대전화 모양 N줄」(값은 찍지 않음) [레드]
   make log-scan           # 앱 로그와 Loki를 따로 센다
   make check L=8-5
   ```
2. **원천에서 줄입니다(✏️ `mall-common/.../log/WebLogAspect.java`).** 응답 본문(`result`)은 남기지 않습니다. 요청 인자는 이름 허용 목록(`LogMask.ALLOWED_PARAMS`: `pageNum`·`pageSize`·`id` …) 밖이면 이름만 남기고 값은 `***`. 줄은 INFO에서 DEBUG로 내리고, `logback-spring.xml`에서 이 로거를 INFO로 둡니다(운영에서는 안 찍힘).
3. **토큰과 사용자 이름(F39, ✏️ `JwtAuthenticationTokenFilter`).** 요청마다 찍던 `checking username:…`·`authenticated user:…`를 DEBUG로 내립니다. 검증 실패 토큰은 이미 남기지 않습니다(5-2).
4. **마지막 그물(✏️ 새 파일 `LogMask.java`·`MaskingConverter.java`, `logback-spring.xml`).** `<conversionRule conversionWord="m" …MaskingConverter/>`(`msg`·`message`도)를 `include`보다 먼저 두면 콘솔·파일 출력의 `%m`이 이 변환기를 지납니다. JWT 모양(`eyJ`로 시작하는 점 세 마디) → `eyJ***`, 휴대전화 모양(앞뒤가 영문·숫자가 아닌 `01x-xxxx-xxxx`) → `010-****-****`, `"password":"…"` → `***`. 놓친 것을 잡는 마지막 단계일 뿐, 원천에서 줄이는 것이 먼저입니다. 방어 스위치 값은 새 파일 `LogMaskBridge`(mall-security)가 앱이 뜰 때 넣습니다.
5. **수집기에서 한 번 더(✏️ `infra/observability/alloy/config.alloy`, 새 파일 `rules/collector.yaml`).** 같은 패턴의 줄에 먼저 `masked_at_collector="true"`·`leak=jwt|phone|password` 레이블을 붙이고 값을 가립니다. 이 줄이 생기면 앱 단계가 놓친 것이라 `log.leak.masked_at_collector` 경보가 울립니다.
6. **확인합니다.**
   ```bash
   make up STACK=spring
   make wipe-logs          # (선택) 가리기 전에 Loki에 들어간 줄 비우기. 운영에서는 보관 기간·삭제 절차가 따로 있다(14장)
   make replay T=21        # 앱 로그·Loki 모두 0건 [그린]
   make collector-test     # 일부러 새는 줄 하나(가짜 토큰) → Loki에는 eyJ***, masked_at_collector="true" → 1~2분 뒤 경보 메일
   make check L=8-5        # 7개 통과(trace_id·주문 번호는 가리지 않는 정상 시험 포함)
   ```
   Grafana 「Explore」에서 같은 시간대 줄을 열어 trace_id는 남고 값은 사라진 모습을 봅니다.
7. **스위치.** `make switch K=log-mask V=off` → `make replay T=21` [레드] → `V=on`. 수집기 가리기는 끌 수 없습니다(그래서 스위치를 꺼도 Loki 쪽은 가려지고 경보가 울립니다).

## 막힐 때
- 변환기만 넣고 `WebLogAspect`를 그대로 두면 정규식이 못 잡는 이름·주소는 계속 남습니다. 원천 줄이기가 먼저입니다.
- 정규식이 너무 넓으면 주문 번호·trace_id·해시까지 가립니다. 휴대전화 모양은 앞뒤가 영문·숫자가 아닐 때만 잡게 했습니다.
- `make collector-test`는 랩 도구가 앱 컨테이너의 표준 출력에 줄 하나를 직접 씁니다(앱 코드는 고치지 않음). 수업 중 일부러 `log.info("debug token=" + token)`을 넣어 봤다면 꼭 되돌립니다.
- Express: `diffs/s8-05/express.diff`는 EverShop 로거(winston)에 같은 가리기 형식을 넣고, 오류 처리기가 요청 본문을 남기지 않게 합니다.

## 남는 이벤트
`log.leak.masked_at_collector`(WARN, 수집기 레이블 → Grafana 규칙)

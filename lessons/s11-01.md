# 11-1 검사한 URL과 쓰는 URL이 다르다
⏱ 약 8분 · 원리 수업(고치기 없음, `make check` 없음) · 아키텍처 변화 없음 · 재연 T28

**파서 차이**는 같은 문자열을 검사하는 코드와 쓰는 코드가 서로 다르게 읽는 것입니다. 검사가 「괜찮다」고 본 주소를 브라우저는 다른 곳으로 읽습니다.

> 안전 원칙: 재연은 OWASP 치트시트 수준의 교과서 예시 세 개만 보냅니다. 도메인은 모두 `.example`이고, 브라우저를 열지 않고 응답의 `Location` 헤더만 봅니다.

## 따라 하기
1. **시작 지점으로 갑니다.**
   ```bash
   make goto L=11-1
   make up STACK=spring
   ```
2. **코드를 봅니다(`mall-portal/.../controller/DaonRedirectController.java`, 교육용 추가).** `GET /daon/go?next=`는 로그인 뒤 원래 보던 화면으로 보내는 기능입니다. `next`가 `/`로 시작하거나 `https://shop.daon.example`로 시작하면 그대로 `Location`에 넣습니다. 검사는 **문자열 앞부분**을 보고, 쓰는 쪽(브라우저)은 같은 문자열을 **URL 파서**로 다시 읽습니다.
3. **재연합니다.**
   ```bash
   make replay T=28
   ```
   | 예시 | 검사 코드가 본 앞부분 | 브라우저가 갈 호스트 |
   |---|---|---|
   | `//other.example/welcome` | `/`로 시작 | `other.example`(슬래시 두 개 = 다른 호스트) |
   | `https://shop.daon.example.other.example/welcome` | 허용 주소로 시작 | `shop.daon.example.other.example` |
   | `https://shop.daon.example@other.example/welcome` | 허용 주소로 시작 | `other.example`(`@` 앞은 사용자 정보) |

   셋 중 하나라도 허용 목록 밖 호스트면 [레드]입니다.
4. **탐지 신호를 찾아봅니다.** 지금은 이동이 기록되지 않습니다. 11-2에서 `redirect.denied.not_allowed`를 심습니다.
   ```bash
   make logs S=mall-portal | grep "/daon/go" | tail -5
   ```

## 막힐 때
- 「진짜 이동하나?」: 재연은 브라우저를 열지 않습니다. 브라우저는 `Location` 헤더를 지금 주소 기준의 URL로 읽어 그 호스트로 갑니다(표의 오른쪽 칸).
- `/daon/go`가 404: 시작 지점이 맞지 않습니다. `make goto L=11-1`.
- 코드 리뷰에서 찾을 모양: `startsWith`·`endsWith`·정규식으로 주소를 검사하고, 그 **문자열**을 그대로 리다이렉트·요청·파일 경로에 쓰는 곳.

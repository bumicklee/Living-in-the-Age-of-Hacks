# 2-2 소유권 검사를 어디에 둘까: 컨트롤러·서비스·쿼리
⏱ 약 9분 · 고칠 파일 1개 · 바뀌는 줄 8줄

## 따라 하기
1. **레드인 것부터 봅니다.**
   ```bash
   make replay T=01
   make check L=2-2
   ```
   bob 토큰으로 alice의 주문 9001을 조회하면 받는 사람·전화·주소가 그대로 나옵니다.
2. **고칩니다.** `spring/mall-portal/.../service/impl/OmsPortalOrderServiceImpl.java`의 `detail()`에서 ✏️ 2-2 표시를 찾아 바꿉니다.
   ```java
   UmsMember member = memberService.getCurrentMember();
   OmsOrderExample orderExample = new OmsOrderExample();
   orderExample.createCriteria().andIdEqualTo(orderId).andMemberIdEqualTo(member.getId()).andDeleteStatusEqualTo(0);
   List<OmsOrder> orders = orderMapper.selectByExample(orderExample);
   if (CollUtil.isEmpty(orders)) {
       Asserts.fail("주문을 찾을 수 없습니다");
   }
   OmsOrder omsOrder = orders.get(0);
   ```
   - 회원 ID는 요청 값이 아니라 로그인 정보(`getCurrentMember()`)에서 가져옵니다.
   - 소유권은 조회 조건에 넣습니다. 먼저 읽고 나중에 비교하면, 비교를 빠뜨린 다른 기능에서 같은 일이 또 생깁니다.
   - 남의 주문과 없는 주문은 같은 답을 받습니다. 주문이 있다는 사실도 알려 주지 않습니다.
3. **확인합니다.**
   ```bash
   make check L=2-2      # 고친 소스로 앱을 다시 빌드한 뒤 시험을 돌립니다(1분쯤)
   make replay T=01      # [그린] 막힘
   ```
   alice가 자기 주문을 보는 정상 요청 시험도 함께 그린이어야 합니다.

# 7-2 SBOM과 악용 중 취약점(KEV) 대조
⏱ 약 9분 · 고칠 파일 `pom.xml` 2개 + 새 파일 1개(`security/vuln-decisions.yaml`) · 아키텍처 변화 없음

권고가 수백 개 나와도 지금 악용되는 것은 몇 개 되지 않습니다. 부품 목록(SBOM)과 「악용 중 취약점 목록(KEV)」을 맞대어 고칠 순서를 정합니다. 랩은 날짜를 박은 사본으로 돌아서 인터넷이 없어도 날마다 같은 결과가 나옵니다.

## 따라 하기
1. **레드인 것부터 봅니다.**
   ```bash
   make goto L=7-2
   make sbom             # [레드] SBOM이 없다: pom.xml에 SBOM을 만드는 설정이 없음
   make check L=7-2
   ```
2. **SBOM 설정을 넣습니다(✏️ `spring/pom.xml`).** `<properties>`에 CycloneDX 플러그인 버전을 더하고, `<build><plugins>` 맨 위에 플러그인을 넣습니다. 빌드(`package`)에는 끼지 않고 `make sbom`이 부를 때만 돕니다.
3. **코드 생성 도구를 운영에서 뺍니다(✏️ `spring/mall-mbg/pom.xml`).** `mybatis-generator-core`를 `<scope>provided</scope>`로 바꿉니다. 코드를 만들 때는 그대로 쓰고, 운영 jar에는 들어가지 않습니다.
4. **SBOM을 만들고 대조합니다.**
   ```bash
   make sbom             # build/sbom/mall-admin.cdx.json · mall-portal.cdx.json · evershop.cdx.json (처음에는 내려받느라 몇 분)
   make kev              # [1] KEV 일치  [2] 외부에 열린 런타임 권고(높음 이상)  [3] 빌드 도구 권고, 그리고 「결정 없음 N건」
   ```
   기본 KEV 파일은 **교육용 가짜 항목 1건**(`LAB-KEV-0001`, dom4j 1.6.1에 붙여 둠)이 든 사본입니다. 실제 CISA 사본(2026-11-06)으로 보려면 `make kev KEV=real`: 이 부품들과 겹치는 것은 0건입니다. 그래도 높음 이상 런타임 권고는 남습니다.
5. **결정을 적습니다(✏️ 새 파일 `security/vuln-decisions.yaml`).** KEV 일치 건과 높음 이상 런타임 권고마다 `upgraded`(올림)·`removed`(뺌)·`exception`(예외)을 적습니다. 예외는 `reason`·`until`(기한)·`owner`(담당)가 모두 있어야 하고, 기한이 지나면 다시 경고합니다. dom4j 1.6.1은 결제 SDK가 끌고 온 것이라 호출 경로를 확인하는 동안 기한 있는 예외로 둡니다.
6. **확인합니다.** `make kev`의 「결정 없음」이 0건, 운영 jar 목록에 mybatis-generator-core가 없음, `make check L=7-2` 10개 통과, `make replay T=18`의 7-2 줄이 「결정 없음 0건」.
7. **시계를 돌려 봅니다.** `DAON_FAKE_NOW=+40d make kev` → 예외 기한이 지난 결정은 다시 「결정 없음」이 되고 WARN 이벤트가 남습니다.

## 막힐 때
- `make sbom`이 처음에는 몇 분 걸립니다(Maven이 부품을 내려받음). 두 번째부터 1분 안팎입니다.
- `provided`로 바꾼 뒤 코드 생성 명령(`Generator`)이 깨지면 코드 생성 실행 경로에서 도구가 빠진 것입니다. 코드를 만들 때는 개발용 실행에 도구를 포함해 부릅니다.
- Express: `diffs/s7-02/express.diff`는 SBOM 스크립트와 `overrides`입니다. 적용 뒤 `npm install`로 lock 파일을 다시 만듭니다.
- Spring Boot 패치 버전 묶음(부모 버전)을 올리는 일은 이 랩에서 하지 않습니다. 올릴 버전은 그날 다시 확인합니다. 결정 기록에는 「Spring Boot 패치 묶음으로 올림(예외, 기한 있음)」으로 적어 둡니다.

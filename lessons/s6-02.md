# 6-2 설정 파일·git 이력·이미지 속 시크릿 찾기
⏱ 약 9분 · 고칠 파일 설정 yml 10개 + 새 파일 6개 · 아키텍처 A4(그대로)

`make scan-secrets`는 시크릿을 **찾기만** 합니다. 값은 화면에 찍지 않고(gitleaks `--redact`) 규칙 이름·파일 이름·건수만 보여 줍니다.

## 따라 하기
1. **기본 규칙이 놓치는 것부터 봅니다.**
   ```bash
   make goto L=6-2
   make scan-secrets RULES=default   # 0건. 기본 규칙은 yml 평문 비밀번호를 놓칩니다(Postman 토큰 5건은 HISTORY=1 이력 검사에서 보임)
   make scan-secrets                 # 아직 .gitleaks.toml이 없어 기준 규칙: 평문 자격증명 20여 건
   make scan-secrets HISTORY=1       # 지운 파일의 옛 커밋까지(이력은 다시 쓰지 않으니 줄지 않습니다)
   make scan-secrets IMAGE=mall-portal   # 빌드된 이미지 속 설정 파일
   make check L=6-2
   ```
2. **규칙을 보강합니다(손으로).** 저장소 맨 위 `.gitleaks.toml`에 규칙 두 개를 더합니다: ① yml·properties의 `password`·`secret`·`access-key` 칸에 값이 그대로 있는 줄, ② 원본 데모 기본값 목록과 정확히 같은 값. 자리 표시(`${…}`)와 빈 값은 잡지 않습니다.
3. **오탐은 한 건씩 이유를 적어 허용합니다.** `.gitleaksignore`의 지문 바로 윗줄에 `# 이유: …`가 없으면 시험이 실패합니다. 규칙을 넓게 끄지 않습니다.
4. **커밋 전에 막습니다.** `make hooks`가 `.git/hooks/pre-commit`을 설치합니다(시크릿이 든 변경은 커밋이 멈춥니다). CI에서는 7-5에서 같은 명령을 단계로 넣습니다.
5. **작업 트리를 정리합니다(✏️ 6-2 표시 10곳).** 설정 파일의 값을 `${DAON_DB_PASSWORD}` 같은 자리 표시로 바꾸고, 값은 `infra/.env`(가짜 값, git에 넣지 않음)가 compose를 거쳐 환경 변수로 넣습니다. 실제 값을 어디서 가져올지는 6-3입니다.
6. **이력은 정리하지 않고 교체합니다.** `infra/secrets/rotation-list.yaml`에 교체 대상(이름·위치·상태, 값 없음)을 적습니다. 교체가 정리보다 먼저입니다. 6-3·6-4에서 `rotated`로 바뀝니다.
7. **미끼를 남깁니다.** Postman 컬렉션의 토큰 5개를 「쓰면 안 되는 가짜 토큰」 표시로 바꿨습니다. 그 문자열이 요청에 오면 필터가 거부하고 `secret.canary_used`를 남깁니다(저장소나 문서가 밖으로 샜다는 신호).
8. **확인합니다.** `make scan-secrets` 0건, `make scan-secrets IMAGE=mall-portal` 0건, `make check L=6-2` 11개 통과.
9. **스위치.** `make switch K=secret-canary V=off`면 미끼 토큰이 거부도 기록도 되지 않습니다.

## 막힐 때
- 이미지 점검은 `make up`으로 빌드된 `daon/mall-portal:dev`가 필요합니다. 이미지에 구워진 것은 jar 안 `application*.yml`이라, 값을 자리 표시로 바꾸면 이미지에도 값이 남지 않습니다.
- `.env`를 직접 고쳤다면 `.env.example`에 새로 생긴 항목만 `make up`이 덧붙입니다(내 값은 그대로).

## 남는 이벤트
`secret.canary_used`(WARN, target `canary:<이름>`)

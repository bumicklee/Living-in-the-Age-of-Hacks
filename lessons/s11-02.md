# 11-2 한 번 파싱해서 검사와 사용에 같이 쓰기
⏱ 약 10분 · 고칠 파일 자바 1개(`DaonRedirectController`) + 새 파일 1개(`mall-security/.../securekit/SafeRedirect.java`) · 아키텍처 변화 없음 · 방어 스위치 `safe-redirect`

주소를 **한 번만** 읽고, 그 결과 객체를 끝까지 들고 가면 두 번 해석될 틈이 없습니다.

## 따라 하기
1. **레드부터 봅니다.**
   ```bash
   make goto L=11-2
   make replay T=28            # 세 예시가 허용 목록 밖으로 [레드]
   make check L=11-2
   ```
2. **한 번 파싱(✏️ 새 `SafeRedirect.java`).** `resolve(String next, Set<String> allowedHosts)` 한 메서드입니다.
   - `new URI(next)` 한 번. 예외가 나면 거부(실패하면 막는다) → `normalize()` → 규칙 검사 → **같은 URI 객체**를 돌려줍니다.
   - 규칙 1(기본안, 상대 경로만): 스킴·호스트(authority)가 없고, 경로가 `/` 하나로 시작하고, 두 번째 글자가 `/`나 `\`가 아니다.
   - 규칙 2(외부 이동이 꼭 필요할 때): 스킴 `https`만, 사용자 정보 없음, 호스트가 허용 목록과 **정확히 같음**(`endsWith` 금지), 포트 없음.
   - 거부하면 `/`(기본 화면). 오류 화면을 띄우지 않습니다.
   - 규칙은 URI 부품(스킴·호스트)과 함께 **내보낼 글자**(`toASCIIString()`, `Location`에 그대로 들어감)에도 겁니다. 예: `///x`는 `URI`가 경로 `/x`로 읽지만 글자는 `///x` 그대로라 브라우저는 `x`라는 호스트로 갑니다. 한 번 파싱한 뒤에도 「무엇을 내보내는가」를 검사합니다.
3. **이동(✏️ `DaonRedirectController.java`).** `ResponseEntity.status(302).location(d.location())` — 검사한 바로 그 객체로 `Location`을 만듭니다. 원래 문자열은 다시 쓰지 않습니다. 허용 호스트는 설정 `daon.redirect.allowed-hosts`(기본 `shop.daon.example`).
4. **⑤ 탐지.** 거부하면 `redirect.denied.not_allowed`(WARN, target `path:/daon/go`, reason 「허용 목록 밖 이동 주소(규칙 N)」). **받은 주소 원문은 넣지 않습니다.** 공격자가 넣은 값이고 로그 줄을 꾸미는 통로가 됩니다.
5. **확인합니다.**
   ```bash
   make up STACK=spring
   make replay T=28            # 세 예시 모두 Location: / [그린]
   make check L=11-2           # 7개(정상 2개: /orders/9001, https://shop.daon.example/orders/9001은 그대로 이동)
   make logs S=mall-portal | grep redirect.denied
   ```
6. **스위치.** `make switch K=safe-redirect V=off` → `make replay T=28` 레드 → `V=on`.

## 막힐 때
- 검사는 URI 객체로 하고 이동은 원래 문자열로 하면 처음 문제로 돌아갑니다. 코드 리뷰에서 가장 자주 보는 실수입니다.
- `URI.create()`는 `IllegalArgumentException`, `new URI()`는 `URISyntaxException`을 던집니다. 어느 쪽이든 거부로 처리합니다.
- `host.endsWith("daon.example")`는 `evildaon.example`도 통과시킵니다. 정확히 같은지 비교합니다.
- Express: `diffs/s11-02/express.diff`는 같은 기능(`/api/daon/go`)을 `new URL(next, base)` 한 번 파싱 + `url.origin === base.origin` 비교로 만듭니다. WHATWG 파서는 `\`를 `/`처럼 읽으므로 origin 비교가 그것까지 막습니다.

## 남는 이벤트
`redirect.denied.not_allowed`(WARN). 경보 후보: 같은 IP `count` ≥ 5 / 10분(피싱 링크를 만들어 보는 시도).

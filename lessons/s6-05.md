# 6-5 오류 응답과 관리용 엔드포인트
⏱ 약 7분 · 고칠 파일 설정·compose·자바 9개 + 새 파일 4개

`make replay T=17`은 두 앱에 로그인 없이 관리·문서 경로를 한 번씩 요청해 응답 코드 표만 보여 줍니다(본문은 읽지 않음).

## 따라 하기
1. **레드인 것부터 봅니다.**
   ```bash
   make goto L=6-5
   make replay T=17     # Swagger UI·/v3/api-docs·/actuator가 로그인 없이 200
   make check L=6-5
   ```
2. **오류 응답을 숨깁니다(✏️ `GlobalExceptionHandler`).** DB 예외는 `{"code":500,"message":"요청을 처리하지 못했습니다","trace_id":"…"}`만 내보내고 원인은 같은 `trace_id`로 서버 로그에만 남깁니다. `e.printStackTrace()` 7곳은 로거로 바꿉니다(✏️ 표시). 모든 예외를 한꺼번에 500으로 바꾸는 일은 9-2입니다.
3. **관리용 엔드포인트를 닫습니다(✏️ 두 앱 `application.yml`).** 허용 목록에서 `/actuator/**`·`/druid/**`를 빼고, `management.server.port: 8081`로 나누며 노출은 `health` 하나. compose는 이 포트를 PC에 열지 않고 상태 확인(healthcheck)만 8081을 봅니다.
4. **운영에서 API 문서를 끕니다.** `DocsClosedPostProcessor`가 prod 프로필에서 `springdoc` 두 개를 false로 덮습니다.
5. **두드린 경로를 남깁니다.** `EndpointProbeFilter`가 로그인 없이 관리·문서 경로를 요청하면 `recon.endpoint_probe`(INFO)를 남깁니다.
6. **확인합니다.** `make check L=6-5` 6개 통과. 닫힌 경로는 404가 아니라 401일 수 있습니다(둘 다 「열리지 않음」).
7. **스위치.** `make switch K=error-mask V=off`는 옛 문구 응답, `K=docs-closed V=off`는 문서 화면이 다시 열립니다.

## 남는 이벤트
`recon.endpoint_probe`(INFO)

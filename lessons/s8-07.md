# 8-7 경보 대응 시간과 알림 피로
⏱ 약 7분 · 고칠 파일 설정 1개(`infra/observability/rules/notify.yaml`) · 아키텍처 A5 그대로 · 방어 스위치 없음(설정 수업) · 미션은 수업 노트 `make lesson L=8-mission`

경보가 울렸는데 아무도 움직이지 않으면 경보가 없는 것과 같습니다. 이 수업은 등급·묶기·다시 보내기 간격·런북·다시 알림을 정하고, 모의 훈련으로 「경보 → 확인」 시간을 잽니다.

## 따라 하기
1. **레드인 것부터 봅니다.**
   ```bash
   make goto L=8-7
   make drill              # 번호 훑기·대량 조회·감사 로그 줄 지우기 + 정상 사용 → 2분 반 뒤 받은 편지함을 셈
   make check L=8-7
   ```
   Mailpit에 같은 원인의 메일이 여러 통 쌓이고 어느 것이 급한지 알 수 없습니다(알림 피로).
2. **등급(`course/SECURITY_EVENTS.md`의 경보 후보 칸).** 칸에 `(P1)`·`(P2)`·`(P3)`가 적혀 있으면(몇 줄은 이미 적혀 있음, 고쳐도 됨) `make alert-rules`가 규칙에 `severity` 레이블을 붙입니다(없으면 P2). 예: `audit.chain.broken`·`deploy.denied.unsigned_image`·`egress.denied.internal_address`는 P1, 번호 훑기·대량 조회는 P2, `input.unexpected_fields`는 P3.
3. **알림 정책(✏️ `infra/observability/rules/notify.yaml`).**
   - 묶기: `group_by: [event, actor]`, 같은 묶음은 30분 안에 다시 보내지 않음(`repeat_interval: 30m`). trace_id로 묶으면 묶음이 생기지 않습니다.
   - 등급별 길: P1 바로(30분마다 다시), P2 묶어서, P3 주간 보고 주소(`weekly-report@`)로 한 통에.
   - 제목에 등급 `[다온 경보][P2] …`, 본문에 런북 주소 `docs/runbooks/<event>.md`(먼저 볼 질의·첫 조치·누구에게 알리나).
   - 다시 알림 길: `alert.escalated.unacknowledged`는 한 단계 위 담당(`lead@`)으로. P1 길보다 **먼저** 둡니다.
   - 기준 시간(P1 확인 15분·첫 조치 1시간, P2 업무 시간 안 4시간)은 이 강의의 예시 값입니다. 회사마다 다릅니다.
4. **확인합니다.**
   ```bash
   make alert-rules        # 등급을 바꿨다면 규칙 다시 만들기(Grafana 다시 뜸)
   make drill              # 메일 수가 줄고 제목에 등급이 붙는다
   make ack ID=access.denied.not_owner
   make drill-report       # 등급별 「경보 → 확인」 시간 표. 15분 넘게 확인 안 된 P1 → alert.escalated.unacknowledged → lead@로 다시 알림
   make check L=8-7        # 4개 통과
   ```
5. **⑤ 탐지: 경보를 지켜보는 경보.** 기준 시간(`DAON_ACK_LIMIT_MIN`, 랩 15분) 안에 확인되지 않은 P1이 있으면 `make drill-report`가 `alert.escalated.unacknowledged`를 남기고, 알림 정책이 lead@로 보냅니다.

## 막힐 때
- 모든 경보를 P1로 두면 P1이 의미를 잃습니다. P1은 「지금 사람이 움직이지 않으면 피해가 커지는 것」만입니다.
- 훈련 결과를 「느리다」로만 끝내지 않습니다. 알림이 늦었나(평가 30초·묶음 대기), 사람이 늦었나, 런북이 없었나로 나눠 적습니다.
- 알림 정책을 고친 뒤 Grafana를 다시 띄워야 읽습니다(`make up`이 설정 변화를 보고 다시 띄움).
- Express: 설정 수업이라 diff가 없습니다. 규칙이 두 스택에 똑같이 걸립니다(EverShop의 SECURITY 줄도 같은 수집기가 읽음).

## 남는 이벤트
`alert.escalated.unacknowledged`(WARN, 도구 이벤트)

SQL 인젝션은 **사용자가 보낸 값이 쿼리 문장의 일부가 되는 것**입니다. 이 수업은 사고와 원리를 보고, 마지막에 다온마켓 원본에 같은 실수가 있는지 한 번 찾아봅니다.

## 다온마켓에서 한 번 찾아보기
MyBatis XML에서 문자열을 그대로 끼워 넣는 표기는 `${…}`입니다. 원본 소스에서 찾아봅니다.
```bash
grep -rln '\${' spring/*/src/main/resources --include='*.xml' | wc -l   # ${가 있는 XML 파일 수(로그 설정 포함)
grep -rn '\${' spring/*/src/main/resources --include='*.xml' | grep -v 'criterion.condition\|orderByClause' | grep -v 'logback\|generatorConfig'
```
- 생성 매퍼 76개에 있는 `${criterion.condition}`과 `order by ${orderByClause}`는 코드 안 상수만 받습니다. 원본이 잘한 곳입니다.
- 두 번째 명령에 남는 줄이 다온마켓이 새로 만든 상품 검색입니다([교육용 추가]). 다음 수업에서 고칩니다.

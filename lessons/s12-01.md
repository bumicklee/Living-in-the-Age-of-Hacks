# 12-1 연동 토큰 하나로 700곳: Salesloft Drift
⏱ 약 8분 · 사고 수업(고치기 없음, `make check` 없음) · 아키텍처 변화 없음 · 재연 T33(12-2에서)

OAuth 토큰은 **이미 끝난 로그인**입니다. 도난되면 비밀번호도 MFA도 다시 묻지 않습니다. 피해 크기는 토큰의 **수명 · 범위 · 사용 위치** 세 변수가 정합니다.

> 「700곳」은 보도 수치입니다. 원문(Google GTIG)은 「다수의 Salesforce 인스턴스」라고만 썼습니다. 화면과 말에 「보도 기준」을 붙입니다.

## 따라 하기
1. **세 사고를 한 표로 봅니다(영상의 그림).** Salesloft Drift(2025-08), GitHub·Heroku·Travis CI(2022-04), Microsoft Midnight Blizzard(2024-01).
   | | 수명 | 범위 | 사용 위치 | 2차 피해 |
   |---|---|---|---|---|
   | Drift | 갱신 토큰으로 계속 | 고객 회사 Salesforce 데이터 내보내기 | 어디서든 | 내보낸 데이터 속 AWS 키·토큰 |
   | GitHub(Heroku·Travis) | 사용자 토큰 | 비공개 저장소 | 어디서든 | 저장소 속 AWS 키 → npm 인프라 |
   | Midnight Blizzard | 테스트 테넌트의 앱 | 고권한 앱 생성 | 어디서든 | 메일함 |
2. **다온마켓이 「토큰을 내주는 쪽」인 자리를 봅니다(마지막 1분).**
   ```bash
   make goto L=12-2
   make up STACK=spring
   ```
   `mall-portal/.../partner/DaonPartnerController.java`(교육용 추가) 머리말의 「지금 설정」: 범위 `*`, 만료 없음, 어디서든 받음. **세 변수가 모두 열려 있습니다.**
3. **다음 수업으로 잇습니다.** 최소 범위·짧은 수명·회전(12-2) → 바인딩(12-3) → 연동 앱 대장·내보내기 경보·앱 단위 일괄 폐기(12-4).

## 막힐 때
- 「우리는 OAuth 서버가 아니니 해당 없다」: 파트너에게 API 키를 건네는 순간 같은 자리에 섭니다. 이름이 토큰이든 키든 같습니다.
- Drift 사고에서 토큰 폐기일(8월 20일)이 활동이 끝난 날(18일)보다 늦었습니다. 12-4의 내보내기 경보가 이 이틀을 줄이는 장치입니다.

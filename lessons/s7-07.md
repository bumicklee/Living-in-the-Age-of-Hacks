# 7-7 역직렬화·업데이트 무결성
⏱ 약 12분 · 고칠 파일 자바 2개 + 새 파일 1개 · 아키텍처 변화 없음 · 방어 스위치 `cache-type-allowlist`

**역직렬화**는 저장소에서 읽은 글자를 다시 객체로 만드는 일입니다. 글자 안에 「이 값은 어떤 클래스다」(`@class`)가 적혀 있고 앱이 그 이름대로 객체를 만들면, 저장소에 쓸 수 있는 사람이 앱이 만들 객체의 타입을 고르게 됩니다. 다온마켓(mall 원본)의 Redis 직렬화기는 「아무 타입이나 허용」으로 설정돼 있습니다. 앱 자신·다른 앱·백업 복원처럼 Redis에 쓰는 경로는 비밀번호를 걸어도 남습니다.

> 안전 원칙: 이 수업은 공격 코드를 만들지 않습니다. 재연(방어 확인)은 허용 목록 밖의 **무해한 JDK 클래스**(`AtomicLong`, 숫자 하나를 담는 클래스)만 씁니다. 바뀌는 것은 「앱이 무엇을 만들까」 하나입니다.

## 따라 하기
1. **레드인 것부터 봅니다.**
   ```bash
   make goto L=7-7
   make replay T=18d      # 관리자 캐시 키의 글자를 AtomicLong을 가리키게 바꾼 뒤 요청 → 앱 로그에 「AtomicLong cannot be cast … UmsAdmin」: 앱이 우리가 고른 타입을 만들었다
   make check L=7-7
   ```
   (`T=18d`는 새 T 번호가 아닌 방어 확인입니다. 점수판에는 세지 않습니다.)
2. **허용 목록으로 바꿉니다(✏️ `mall-common`의 `BaseRedisConfig`).** `LaissezFaireSubTypeValidator`(아무 타입이나 허용)를 지우고 `BasicPolymorphicTypeValidator`로, `com.macro.mall.model.` 아래와 꼭 필요한 JDK 타입(`ArrayList`·`HashMap`·`Date` 등)만 허용합니다.
3. **형식을 고정해서 읽습니다(✏️ `UmsAdminCacheServiceImpl`, 새 파일 `CacheTypeGuard`).** 관리자 캐시는 JSON **글자 하나**로만 저장하고(글자 안에 클래스 이름이 없음), 읽을 때 호출한 쪽이 정한 타입(`UmsAdmin`)으로만 만듭니다. 글자가 아니거나(예전 형식·남이 쓴 값) 허용 목록 밖 타입이면 → 그 키를 지우고 `null`(= 캐시에 없음, DB에서 다시 읽음)을 돌려줍니다. 사용자는 오류를 보지 않습니다.
4. **⑤ 탐지: 거부하면 남깁니다.** `deserialize.denied.type`(WARN, actor `system:redis-cache`, target `cache:mall:ums:admin:* class:<클래스 이름>`). 클래스 이름은 저장소에 쓴 사람이 정한 값이라 **120자로 자르고 영문·숫자·`.$_`만** 남깁니다(로그 줄 위조 막기).
5. **예전 형식의 캐시를 비웁니다.** 전환 직후 예전 형식 값은 한 번 거부 이벤트가 남고 DB에서 다시 읽힙니다. 미리 비우려면:
   ```bash
   make redis-flush       # mall:* 캐시 키만 지운다(키 이름만 세고 값은 읽지 않는다)
   ```
6. **확인합니다.**
   ```bash
   make replay T=18d      # [그린] 허용 목록이 거부하고 DB에서 다시 읽음
   make check L=7-7       # 7개 통과: 관리자 로그인·회원 로그인 정상 시험 포함
   make logs S=mall-admin | grep deserialize.denied
   ```
7. **스위치.** `make switch K=cache-type-allowlist V=off` → 옛 모습(아무 타입이나 허용, 객체 그대로 형 변환) → `make replay T=18d` [레드]. 끄고 켠 뒤에는 `make redis-flush`로 캐시 형식을 맞춥니다.

## 설계 메모
- 먼저 **타입 고정**(캐시마다 받을 타입을 하나로)을 고르고, 다형 타입이 꼭 필요한 곳에만 **허용 목록**을 씁니다. 이 수업은 둘을 함께 둡니다: 공용 직렬화기는 허용 목록, 관리자 캐시는 타입 고정.
- 회원 캐시·권한 목록 캐시는 7-미션입니다.
- Express: EverShop에는 이런 Redis 역직렬화가 없습니다. 같은 원칙(저장소에서 읽은 글자가 객체의 모양을 정하지 못하게)을 상품 설명(`description`)의 `JSON.parse` 한 곳에 적용한 `diffs/s7-07/express.diff`를 봅니다.

## 막힐 때
- 고친 뒤 관리자 로그인에서 오류가 난다: 예전 형식 값이 남은 것입니다. `make redis-flush`(또는 `make wipe`).
- 「Redis에 비밀번호를 걸었으니 괜찮지 않나요?」: 앱 자신, 다른 앱, 백업 복원 같은 쓰기 경로가 남습니다.
- 화면 하나가 깨진다: 다형 타입이 필요한 캐시까지 타입 고정으로 바꿨는지 봅니다. 캐시별로 담는 타입을 표로 먼저 적고, 필요한 곳만 허용 목록을 씁니다.

## 남는 이벤트

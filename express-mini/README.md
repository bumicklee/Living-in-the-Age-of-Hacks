# 다온마켓 Express 미니

「해킹 서바이벌 가이드」의 Express 실습용 작은 가게입니다. 핵심 보안 실습 13개와 보너스·Express 보강 실습 5개를 내 PC에서 재연하고, 직접 고친 뒤 시험으로 확인합니다. 모든 계정·주소·값은 가짜입니다.

- 코드 버전: v1.0 · 설명서: 「Express 따라하기」 1.0
- 함께 넣은 부품: `vendor/secure-kit-express` 0.1.0(보너스 수업용, MIT)

## 준비물

macOS와 Node.js 24 LTS 하나면 됩니다. Docker나 DB 서버는 필요 없습니다. Windows·Linux에서는 확인하지 않았습니다.

```bash
node -v        # v24.x
npm ci         # 처음 한 번
npm start      # 앱 터미널에 켜 둡니다 → http://127.0.0.1:4300
```

## 명령

| 명령 | 하는 일 |
|---|---|
| `npm start` | 앱 실행. 파일을 저장하면 스스로 다시 시작합니다 |
| `npm run lesson 2-2` | 수업 시작 상태로 바꿉니다(고치던 파일은 `.backup/`에 보관) |
| `npm run replay 2-2` | 켜 둔 앱에 공격을 흉내 낸 요청을 보내 레드·그린을 판정합니다 |
| `npm run check 2-2` | 수업 시험(앱을 켜지 않아도 됩니다) |
| `npm run compare 2-2` | 내 코드와 정답의 다른 줄 |
| `npm run solution 2-2` | 정답 적용(막혔을 때) |
| `npm run reset` | DB와 로그만 처음 상태로 |
| `npm run secret` | 새 비밀 값을 `.env`에 넣기(6-3 수업) |
| `npm run verify-all` | 모든 수업의 시작·정답 상태를 한 번에 확인(1분쯤) |

## 수업

핵심 13개: 2-2, 2-3, 2-4, 2-5, 3-2, 3-4, 4-3, 4-8, 6-3, 6-5, 8-3, 8-5, 10-2.

보너스 15-4는 앞 수업의 고친 상태에서 보안 부품을 연결합니다. Express 보강 18-1~18-4는 미들웨어 순서, 비동기 오류, 세션, 의존성 감사를 다룹니다. 18-4는 앱을 켜지 않고 `package.json`과 잠금 파일을 고칩니다.

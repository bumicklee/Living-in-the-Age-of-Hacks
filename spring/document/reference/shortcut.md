# IDEA 단축키를 Eclipse 스타일로 설정

- 클릭File->Settings->Keymap, 단축키 스타일로 다음을 선택합니다Eclipse
- 아래 표의 영어 설명에 따라 검색하고 해당 단축키로 변경

Eclipse | IDEA | 영문 설명 | 한글 설명
----|----|----|----
ctrl+shift+r	|ctrl+shift+r	|Navigate->File	|워크스페이스에서 파일 찾기
ctrl+shift+t	|ctrl+shift+t	|Navigate->Class	|클래스 정의 찾기
ctrl+shift+g	|ctrl+shift+g	|Edit->Find->Find Usages	|메서드가 어디서 호출되는지, 변수가 어디서 사용되는지 찾기
ctrl+t	|ctrl+t	|Other->Hierarchy Class	|클래스 상속 구조 보기
ctrl+o	|ctrl+o	|Navigate->File Structure	|클래스 안의 메서드 검색
shift+alt+z	|shift+alt+z	|Code->Surround With	|자주 쓰는 코드 블록 생성
shift+alt+l	|shift+alt+l	|Refactor->Extract->Variable	|변수 추출
shift+alt+m	|shift+alt+m	|Refactor->Extract->Method	|메서드 추출
alt+left	|alt+left	|Navigate->Back	|이전 작업 위치로 되돌아가기
alt+right	|alt+right	|Navigate->Forward	|이전 작업 위치 앞으로 이동
ctrl+home	|ctrl+home	|Move Caret to Text Start	|클래스 맨 앞으로 이동
ctrl+end	|ctrl+end	|Move Caret to Text End	|클래스 맨 뒤로 이동
ctrl+2 L	|shift+alt+l	|Refactor->Extract->Variable	|변수 추출
ctrl+e	|alt+r	|View->Recent Files	|최근 열어 본 파일
ctrl+w	|ctrl+w	|Close	|현재 창 닫기
alt+/	|alt+/	|Code->Completion->Basic	|변수 생성 힌트
ctrl+1	|ctrl+1	|Other->Show Intention Actions	|가능한 작업 힌트
ctrl+h	|ctrl+h	|Find in Path	|전체 검색
alt+위/아래 화살표	|alt+위/아래 화살표	|Code->Move Line Up/Down	|코드 한 줄 이동
ctrl+alt+위/아래 화살표	|ctrl+alt+위/아래 화살표	|Editor Actions->Duplicate Lines	|한 줄 복사
ctrl+shift+j	|ctrl+shift+j	|Other->Fix doc comment	|메서드 주석
없음|alt+enter	|Other->Show Intention Actions	|자주 쓰는 작업 힌트
Ctrl+F	|Ctrl+F/Ctrl+R	|Find/Replace	|찾기 및 바꾸기
Shift+Enter	|Shift+Enter	|Start New Line	|새 줄 시작
Ctrl+Alt+S	|Ctrl+Alt+S	|Generate	|getter, setter, toString 등 생성

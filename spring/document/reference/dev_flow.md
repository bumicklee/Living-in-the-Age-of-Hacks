### 상품 관리 

> **상품 카테고리 관리**

- 상위 카테고리 번호로 카테고리 목록을 페이지 단위로 조회
- 카테고리 추가, 편집, 삭제
- 카테고리 상품 이동

> **상품 브랜드 관리**

- 브랜드명으로 검색해 브랜드 목록을 페이지 단위로 조회
- 브랜드 추가, 편집, 삭제
- 현재 브랜드의 모든 제품 보기

> **상품 속성 카테고리 관리**

- 상품 속성 카테고리(이름) 추가
- 전체 상품 속성 카테고리 페이지 조회
- 단일 상품 속성 카테고리 삭제
- 단일 속성 카테고리 이름 수정
- 단일 속성 분류 정보 조회

> **상품 속성 관리**

- 카테고리로 속성 목록 또는 파라미터 목록 조회(페이징, 유형 지원)
- 상품 속성 추가
- 단일 상품 속성 조회
- 상품 속성 편집
- 상품 속성 일괄 삭제
- 전체 상품 속성 페이지 조회

> **상품 추가**

- 상품 카테고리 선택: 상품 카테고리 id로 카테고리 조회
- 브랜드 선택: 전체 브랜드 조회
- 배송비 템플릿 선택: 전체 배송비 템플릿 조회
- 회원 가격 설정: 모든 회원 등급을 조회하여 전달List<PmsMemberPrice>
- 단계별 가격 추가: 파라미터 전달List<PmsProductLadder>
- 금액 할인 가격 설정: 파라미터로 전달List<PmsProductFullReduction>
- 상품 속성 분류 선택: 모든 상품 속성 카테고리를 조회하고, 상품 속성 카테고리 id로 규격과 파라미터 조회(type=0->규격;type=1->파라미터)
- 규격 선택 및 재고 정보 생성: 프런트엔드 구현
- sku 재고 정보 추가: 파라미터 전달List<PmsSkuStock>
- 속성 이미지 설정: pic과 album_pics 필드에 설정
- 상품 파라미터 추가: 파라미터 전달List<PmsProductAttributeValue>
- 사용자 정의 상품 규격 추가: 파라미터 전달List<PmsProductAttributeValue>
- 연관 기획전: 파라미터 전달List<CmsSubjectProductRelation>관계
- 연관 엄선: 파라미터 전달List<CmsPrefrenceAreaProductRelation>관계

> **상품 수정**

- 상품 id로 상품 정보 조회
- 상품 기본 정보 조회: 상품 카테고리명, 브랜드명, 배송비 템플릿명
- 상품 프로모션 정보 조회: 상품의 회원 가격, 구간별 가격, 금액 할인 가격
- 상품 속성 정보 조회: 상품 속성 유형명, sku 재고 정보, 속성 분류별 규격 및 파라미터 값
- 상품 연관 정보 조회: 상품 연관 기획전 및 연관 추천
- 상품 정보 수정: 상품 속성 카테고리와 규격은 수정할 수 없으며 단일 sku의 수정, 삭제, 추가만 지원; 상품 속성 카테고리와 규격을 수정할 수 있는 경우: 수정 후 기존 sku 재고와 속성 카테고리가 함께 표시됨

> **상품 페이지 조회**

- 상품 상태: 전체 상품, 판매 중, 판매 중지, 심사 대기, 미통과 (publishStatus verifyStatus)
- 상품명(%name%)
- 상품 코드(productSn)
- 상품 카테고리id(productCategoryId)
- 상품 브랜드id(brandId)
- 일괄 작업: 판매 시작/중지, 추천, 신상품, 카테고리 이동, 휴지통으로 이동, 심사
- 기록 보기: 심사 기록, 작업 로그
- sku:상품 및 sku 번호로 sku 정보 조회, sku 정보 일괄 수정

> **상품 휴지통 관리**

- 휴지통 상품 목록 페이지 조회
- 휴지통 상품 복원 기능

## 프런트 기능

### 상품 검색

> **통합 검색 기능**

- 검색: 상품 제목, 부제목, 키워드로 검색;
- 필터: 카테고리를 선택하지 않았을 때는 검색 결과를 집계해 출현 횟수가 가장 많은 카테고리를 선택하고, 카테고리를 선택한 뒤에는 해당 카테고리의 필터 필드로 필터링할 수 있음;
- 정렬: 신상품, 판매량, 가격순으로 정렬
- 검색 반환 결과: 상품 ID, 상품 이미지, 이름, 부제목, 가격, 상품 판매량, 신상품, 상품 파라미터, 브랜드명, 카테고리명
- API: 데이터베이스에서 관련 데이터를 조회해 es로 가져오기, 데이터 삽입(수정) API, 데이터 삭제 API
- 브랜드/카테고리 필터: 검색 결과를 집계해 브랜드, 카테고리, 속성을 반환

> **상품 추천 기능**

- 특정 상품의 연관 상품 추천, 해당 상품의 브랜드(10), 카테고리(6), 이름(8), 키워드(2), 부제목(2) 기준
- 사용자의 최근 일주일 조회 기록으로 상품 추천, 사용자 검색 기록으로 상품 추천

> **상품 인기 검색어 기능**

- 사용자 검색 기록을 집계하여 인기 검색어 생성

> **상품 검색 자동완성 기능** 

- 사용자 검색 기록을 집계하여 인기 검색어 생성
